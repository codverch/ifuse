Optimizing memory loads in emerging agentic AI applications

Finding the execution-time relationships that today’s processors leave unused — and designing hardware mechanisms that put them to work.

Code and artifacts on GitHub Project lead

Motivation

Emerging datacenter applications are changing the demands placed on processors. Applications such as machine learning (ML), databases, graph analytics, and agentic AI increasingly operate on large datasets and follow dynamic execution paths. These behaviors can make individual memory accesses and instructions difficult to predict; as a result, processors may spend time waiting for data, moving data, or maintaining instructions that cannot yet make progress.

Approach

We are studying whether information that emerges during application execution can help processors avoid some of this overhead. Current processor mechanisms often make decisions using information about individual instructions or individual memory accesses. However, the behavior of one instruction can depend on other instructions that execute before or after it. Similarly, the data needed by one instruction may be related to data accessed elsewhere in the execution. These relationships can provide information that is not visible when instructions are considered independently.

Our current work characterizes these relationships in memory-intensive datacenter applications. We are measuring how often they occur, how stable they are across executions, and what makes them predictable despite dynamic control flow and irregular data accesses. We are then using these observations to develop processor mechanisms that exploit predictable execution behavior to reduce unnecessary work and improve processor resource utilization.

Evaluation

We evaluate these mechanisms using representative datacenter workloads and processor-level simulation; our evaluation considers performance, energy efficiency, and hardware cost. Alongside the architectural mechanisms, we are developing the workload characterization and analysis infrastructure needed to identify these opportunities across applications.

Goal

Our goal is to develop a systematic way to identify execution information that existing processor mechanisms leave unused, and to understand when exposing that information to the processor can improve the efficiency of emerging datacenter workloads.
